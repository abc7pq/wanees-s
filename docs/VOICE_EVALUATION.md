# تقييم البنية الصوتية وصوت ونيس

الحالة: **خطة قياس + تجهيزات في الكود. لم تُجرَ المقارنة بعد** (تحتاج مفتاح OpenAI وأجهزة حقيقية). لا يُستبدل شيء في البنية قبل الأرقام.

## البنية اليوم
1. **المكالمة الحية (الأساس):** WebRTC ← OpenAI Realtime، والحقائق من أدوات المحرك (`app/lib/realtime-call.ts`, `realtime-session.ts`).
2. **البديل المحلي (موجود):** Web Speech API للتعرف (`ar-SA`) و`speechSynthesis` للنطق، والرد من `/assistant` (`app/lib/voice-call.ts`). يعمل تلقائيًا عند غياب المفتاح أو فشل المكالمة الحية.
3. **التحليل المحلي للصوت (جديد):** `app/lib/audio-meter.ts` يقرأ الميكروفون وصوت ونيس بـ`AnalyserNode` لتحريك الموجات والشخصية. لا تسجيل ولا طلب سحابي إضافي، ولا يعالَج الصوت مرتين (نفس الـ`MediaStream`).

## الصوت
الافتراضي المؤقت `marin` (أنثوي). المرشحون: `marin`, `coral`, `shimmer`, `sage` عبر `WANEES_OPENAI_REALTIME_VOICE`. الصوت السابق `cedar`.

اختبار الاستماع (لكل صوت، نفس الجمل، مقيّمان على الأقل يتكلمان السعودية):

| المحور | جملة الاختبار |
|---|---|
| اللهجة السعودية | «هلا والله، أبشر، أرتّبها لك الحين» |
| أسماء محلية | «التلفريك في منطقة أفريقيا، وبعده عرض الدولفيناريوم» |
| أرقام وأسعار وأوقات | «خمسين ريال للشخص، الساعة ست ونص، عشرين دقيقة مشي» |
| إنجليزي وسط العربي | «ڤيوز دوم سينما»، «باتل كارت»، «VR» |
| المقاطعة | قاطعها وسط الجملة وسجّل زمن التوقف |
| تغيير النبرة | طلب عادي ثم «ولدي ضاع» |
| الطبيعية | تقييم 1–5 للإيقاع |

## القياس
`createCallTimer` في `realtime-call.ts` يسجّل لكل مكالمة: زمن البدء (الضغط ← فتح القناة) وزمن أول صوت بعد انتهاء كلام الزائر. يُطبع عند إنهاء المكالمة: `wanees.call.timings {"startMs":…,"replyMs":[…]}` (أرقام فقط).

| المقياس | الحية (Realtime) | المحلية (Web Speech) | كيف يُقاس |
|---|---|---|---|
| سرعة بدء المكالمة | — | — | `startMs` |
| زمن الرد بعد كلام الزائر | — | — | `replyMs` (وسيط و p90) |
| فهم اللهجة السعودية | — | — | 30 جملة مسجّلة، نسبة الكلمات الصحيحة |
| أسماء الأماكن | — | — | 23 منطقة + 20 نشاطًا |
| جودة الصوت | — | — | اختبار الاستماع أعلاه |
| التكلفة للدقيقة | — | — | فاتورة المزوّد ÷ دقائق الاختبار |
| استهلاك البيانات | — | — | DevTools ← Network لخمس دقائق |
| الأماكن المزدحمة | — | — | نفس الجمل مع ضجيج 75 dB |
| Safari / Chrome / iOS / Android | — | — | مصفوفة الأجهزة |
| انقطاع الشبكة والمقاطعة | — | — | وضع الطيران 5 ثوانٍ وسط المكالمة |

ملاحظات معروفة قبل القياس (تُتحقق ولا تُفترض): Web Speech على Chrome يرسل الصوت لخدمة Google (ليس محليًا تمامًا)، ودعم `ar-SA` على Safari iOS محدود، ولا يدعم المقاطعة أثناء النطق. لذلك يبقى WebRTC هو الأساس حتى تثبت الأرقام غير ذلك. `AudioWorklet` غير مطلوب اليوم: `AnalyserNode` يكفي للموجات ولا يمس مسار الصوت.
