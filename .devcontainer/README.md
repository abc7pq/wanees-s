# تجربة ونيس s من الجوال (GitHub Codespaces)

نسخة تشتغل في سحابة GitHub ومعها قاعدة بيانات تجريبية خاصة بها. لا تلمس `wanees.win` ولا أي جهاز.

## أول مرة
1. من متصفح الجوال وأنت داخل بحسابك في GitHub افتح: `https://codespaces.new/abc7pq/wanees-s`
2. اضغط **Create codespace**. أول تجهيز يأخذ عدة دقائق (تثبيت، قاعدة البيانات، بناء التطبيقين) ويظهر تقدمه في الطرفية.
3. لما يطلع الرابط البنفسجي في الطرفية افتحه. نفس الرابط موجود في تبويب **Ports** على المنفذ 3100، وأضف له `/e/boulevard-world-demo`.

## بعد كل تحديث
افتح نفس الـ Codespace من `https://github.com/codespaces`. عند فتحه يسحب آخر تعديلات `main` ويعيد البناء إن تغيّر الكود، ثم يطبع الرابط نفسه.

## ملاحظات
- الرابط خاص: يفتح في المتصفح الداخل بحسابك في GitHub فقط.
- الـ Codespace ينام بعد نحو نصف ساعة بلا نشاط؛ افتحه من جديد ويشتغل لوحده.
- المكالمة تعمل بصوت المتصفح بلا مفتاح. لتجربة المكالمة الحية أضف سرًّا باسم `OPENAI_API_KEY` في GitHub ← Settings ← Codespaces ← Secrets لهذا المستودع ثم أعد تشغيل الـ Codespace. المفتاح لا يُكتب في المستودع.
- لوحة المنظّم على المنفذ 3200، وكلمة مرور المالك تُطبع في نهاية التجهيز الأول.
